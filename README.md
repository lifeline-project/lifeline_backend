# Lifeline 
LifeLine is a real-time emergency medicine availability platform designed to help users quickly locate nearby pharmacies that have required medicines in stock. Unlike traditional medicine delivery apps that rely on static inventory and delayed delivery, LifeLine uses a broadcast-based approach to instantly notify nearby pharmacies when a user requests an emergency medicine. Pharmacies can respond in real time, enabling users to reach the nearest available store without delay. The system aims to reduce time wastage during medical emergencies and improve accessibility, especially for elderly users and areas with limited technological infrastructure.  ​
